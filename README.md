# bricks

A collection of **ESP-IDF/C++ components** and support packages for various projects.

## Components

- **chronicler** - Append-only flash event log with sync/disposal metadata and ESP-IDF test/example apps.
- **disnet** - Low-level transport + routing primitives (including ESP-NOW adapter) for mesh-style communication.
- **emlabcpp** - ESP-IDF wrapper/component packaging for upstream `emlabcpp`.
- **events** - Typed wrapper around ESP-IDF event loop APIs (`esp_event`) for safer C++ event dispatch.
- **exceptions** - Exception helpers for ESP-IDF, including traced exceptions and IDF error-to-exception conversion.
- **glaze** - ESP-IDF wrapper/component packaging for upstream `glaze`.
- **schwi** - Header-only host-side discrete-event network simulator with trace/log + visualization export.
